# TTF News 前端

React + TypeScript + Vite，本地资讯工作台。仅使用后端返回的新闻与分析结果；缺失数据不填入演示预测。

```sh
npm install
npm run dev
```

开发页面为 `http://127.0.0.1:5173`，`/api` 代理至 `http://127.0.0.1:8765`。生产运行 `npm run build`，FastAPI 直接提供 `dist/`。无需注册云端 Sites。

页面提供实时新闻、手动输入、详情分析、事件库、覆盖报告与 CSV / JSONL 数据导出。默认深色，可切浅色。右上角支持中文 / English 切换并保存选择。界面使用 React 渲染层本地字典；原新闻与模型输出保留原文，模型分析默认中文，不额外请求模型翻译。界面时间显示新加坡时间，交易窗口明确显示阿姆斯特丹时间。SSE 断线自动重连，并每 15 秒刷新一次作为兜底。

验证：`npm test` 检查五档展示、缺失预测、来源失败、时间截止、实测延迟及来源链接，也检查语言选择、动态计数与原文/输入隔离；`npm run build` 进行 TypeScript 检查与生产构建。实际模型与采集端到端验证由整个项目的后端验收完成。
